# O que é Front-end?

Front-end é a camada de uma aplicação com a qual o usuário interage diretamente.

É responsável por:

- Construção das interfaces;
- Organização visual dos elementos;
- Experiência do usuário (UX);
- Comunicação com os sistemas responsáveis pelo processamento dos dados.

Seu principal objetivo é oferecer interfaces modernas, intuitivas e eficientes. :contentReference[oaicite:1]{index=1}

---

# Importância dos Frameworks Front-end

Atualmente, grande parte das aplicações web utiliza algum Framework Front-end.

Eles são importantes porque permitem:

- Desenvolvimento mais rápido;
- Organização do código;
- Reutilização de componentes;
- Facilidade de manutenção;
- Escalabilidade dos projetos.

As empresas procuram profissionais capazes de desenvolver interfaces rápidas, organizadas e de fácil manutenção. :contentReference[oaicite:2]{index=2}

# Introdução ao JavaScript

A disciplina inicia utilizando JavaScript puro (Vanilla JS).

## O que é Vanilla JS?

É o JavaScript sem frameworks ou bibliotecas externas.

Serve como base para compreender como todos os frameworks modernos funcionam.

Sua importância está em permitir:

- manipulação do HTML;
- comunicação com servidores;
- implementação da lógica da interface;
- criação de aplicações dinâmicas. :contentReference[oaicite:4]{index=4}
